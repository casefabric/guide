# Housekeeping

The major update in this release relates to the underlying dependencies.
<br/>
Database driver versions, Apache Pekko libraries, authentication libraries and more all have been updated.
<br/>
<br/>
Furthermore this release delivers various small improvements and bugfixes, most notably in the sentry network connections to `Case File Items` of type array.
