# Nitty gritty gems

Improving predictability is a core principle of engine builders.
<br/>
This release brings improvements on small details. Small yet important.
<br/>
<br/>
Most notable are the small extensions in the use of the case file items. The behavior when starting a case with a list of items vs adding items in a running case has been aligned to behave exactly the same.
