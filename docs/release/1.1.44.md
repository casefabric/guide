# Java Security Update

This release delivers a new base image that addresses the [Java CVE-2026-114938](https://www.cve.org/CVERecord?id=CVE-2026-114938).
<br/>
The base image for the Case Engine is now [eclipse-temurin:25.0.5.1_2-jre-noble](https://hub.docker.com/layers/library/eclipse-temurin/25-jre-noble/images/sha256-49fa0d811061f2b684eb8d32048c6697890e2b169e2cd6bd329d01f03848a606).
